How the Parser Works (Production → Automaton Transition)

Rule 1 • Transition to Variable
A → aB  ⇒  A --a--> B

Non-terminal → Input symbol → Next state.
When a production pairs an input symbol with a non-terminal variable, it transitions directly to that variable's state.

Rule 2 • Terminal-Only Acceptance
A → a  ⇒  A --a--> F

When a production ends with a terminal, connect it to the final state F.
Because no further variable remains to be expanded, the automaton terminates and reaches acceptance.

What is Right-Linear Grammar?

A Right-Linear Grammar (RLG) is a formal grammar in which every production rule has the non-terminal variable appearing strictly at the rightmost end of the right-hand side.

A → aB  or  A → a

where A and B are non-terminals (variables) and a is a terminal symbol. Right-linear grammars generate the exact class of Regular Languages.

Conversion Rule to Finite Automaton

Every production decomposes directly into an automaton state transition:

A → aB  becomes  A --a--> B
A → a   becomes  A --a--> F

The first non-terminal on the LHS is marked as the initial start state, and F serves as the common accepting final state.
